Overview

📖 Counts, Center, and Spread

Before using summarize() and count(), it helps to review a few data words you have likely seen before. You do not need to calculate these by hand in this chapter. You do need to understand what they mean so you can choose the right function and explain your results.

🐱 Curiosity as an intellectual virtue means choosing where to spend your attention. If these review terms feel rusty, pause here and use this section to refresh them. If you already practiced these ideas (e.g., in the Data Understanding Notebook activity), you can skip this review section and jump to dplyr’s count(). Return if you need a reminder.

Data Terminology

A numeric variable stores numbers that can be measured or calculated, such as mpg, height, or test score.

A categorical variable stores labels or group names, such as state, disease, or cylinder count.

In this chapter, we often group by a categorical variable and then summarize a numeric variable.

Count

A count tells you how many observations there are.

  • For a whole dataset, count means the total number of rows.

  • For grouped data, count means the number of rows in each group.

If you want to know how many cars have 4 cylinders, 6 cylinders, or 8 cylinders, you are asking for a count.

Center

Center describes a typical value.

Mean

The mean is the average.

It adds the values and divides by how many values there are.

If the mean mpg for cars with 4 cylinders is higher than the mean mpg for cars with 8 cylinders, then the 4-cylinder cars are more fuel efficient on average.

Median

The median is the middle value when the data are sorted.

🪞 Median is useful when extreme values might pull the mean too high or too low.

Spread

Spread describes how much the values vary.

Standard Deviation

The standard deviation tells you how far values tend to be from the mean.

  • A small standard deviation means the values are packed closely together.

  • A large standard deviation means the values are more spread out.

If one cylinder group has a much larger standard deviation for mpg, that group has more variability in fuel efficiency.

Range

The range is the distance from the smallest value to the largest value.

🪞 Range gives a quick sense of spread, but it only uses the minimum and maximum values.

🐱 The goal is to know which summary tool matches the question.

  • use count when you want to know how many rows are in a dataset or group

  • use mean when you want an average

  • use standard deviation when you want to describe spread

  • use a categorical variable to make groups

  • use a numeric variable when calculating statistics like mean or standard deviation

We’ll start with counting categories with count() because counts help you see what categories are present before you calculate more complex summaries.

dplyr’s count()

You can use count() to quickly count rows for each category or combination of categories.

count() is especially useful when you want a frequency table.

?count

📜 The SYNTAX

data %>% count(variable_name)

Or, for more than one grouping variable:

data %>% count(variable1, variable2, ...)

Count one variable

🎯 Count how many cars have each cylinder value.

# ⚡ Type this in a Quarto code chunk:
mtcars %>%
  count(cyl)
  cyl  n
1   4 11
2   6  7
3   8 14

🗣 The code above counts how many rows fall into each value of cyl. The result is a new table with one row per cylinder value and a column named n that stores the counts.

🐱 This is the curiosity move here: before I compare or explain anything, I want to know what categories are in the data and how many rows belong to each one. This step helps me understand the data before I ask a bigger data question.

💡 Test knit. Does the table show one row for each cylinder value and a column named n?

count() versus length()

length() counts how many values are in a vector.

count() counts rows in a data frame for each category or combination of categories.

count() with sorting

Sometimes you want to see the biggest groups first.

🎯 Count cars by cylinder and sort from largest count to smallest count.

# ⚡ Type this in a Quarto code chunk:
mtcars %>%
  count(cyl, sort = TRUE)
  cyl  n
1   8 14
2   4 11
3   6  7

🗣 sort = TRUE arranges the result so the largest count appears first. The counts are the same as before; only the row order changed.

Count multiple variables

You can also count combinations of categories.

🐱 This is a good time to indulge curiosity a little further. Counting one variable told us how many cars had each cylinder value. Counting two variables lets us ask a more specific question: how are cylinder values distributed across transmission types?

🎯 Count how many cars fall into each combination of cylinder count and transmission type.

🧐 Notice: In mtcars, am is a coded transmission variable. A value of 0 means automatic, and a value of 1 means manual.

# ⚡ Type this in a Quarto code chunk:
mtcars %>%
  count(cyl, am)
  cyl am  n
1   4  0  3
2   4  1  8
3   6  0  4
4   6  1  3
5   8  0 12
6   8  1  2

🗣 count(cyl, am) creates one row for each unique combination of cyl and am, then counts how many rows are in each combination.

This is useful when one grouping variable is not enough.

If our question is only “How many rows are in each category?”, count() is enough. But what if our question asks about averages, maximums, spread, or other statistics? We’ll need summarize().

dplyr’s summarize()

You can use summarize() to compute summary statistics like the mean, median, etc.

?summarize

📜 The SYNTAX

data %>% summarize(new_column_name = some_operation(column_name))

🎯 Find the overall mean mpg for all cars.

# ⚡ Type this in a Quarto code chunk:
mtcars %>% 
  summarize(mean_mpg = mean(mpg))
  mean_mpg
1 20.09062

🗣 The code above creates a new column called mean_mpg that contains the mean of the mpg column from the mtcars dataset.

We name the new column using new_name = calculation.

🎯 Find several summary statistics for mpg: mean, max, and count of cars.

# ⚡ Type this in a Quarto code chunk:
mtcars %>% 
  summarize(mean_mpg = mean(mpg),
            max_mpg = max(mpg),
            count = n())
  mean_mpg max_mpg count
1 20.09062    33.9    32

🧐 Notice: Do not put pipes %>% inside summarize(). Inside the function, separate each summary calculation with a comma ,.

💡 Test knit. Does the output show one row with three summary columns: mean_mpg, max_mpg, and count?

🤔 summary() is a base R function that gives a quick overall description of an object, such as basic statistics for each variable in a data frame. summarize() from dplyr is used to create your own summary results, usually after group_by(), such as the mean or count for each group.

count() versus summarize()

You can often get the same result in two ways.

🎯 Use group_by() and summarize() to produce the same counts by cylinder.

# ⚡ Type this in a Quarto code chunk:
mtcars %>%
  group_by(cyl) %>%
  summarize(n = n())
# A tibble: 3 × 2
    cyl     n
  <dbl> <int>
1     4    11
2     6     7
3     8    14

🗣 This gives the same idea as count(cyl). The difference is that count() is shorter and faster to write when your main goal is just to count rows.

Use count() when you mainly want frequencies. Use group_by() with summarize() when you want to calculate other statistics too, such as mean and standard deviation.

dplyr’s group_by()

group_by() changes the behavior of summary functions.

📜 The SYNTAX

data %>% group_by(variable1, variable2, ...) %>% some_operation()

🎯 Find the mean mpg for each cylinder count.

# ⚡ Type this in a Quarto code chunk:
cyl_means <- mtcars %>%
  group_by(cyl) %>%
  summarize(mean_mpg = mean(mpg))

🗣 group_by(cyl) splits the cars into groups based on cylinder count, and summarize() calculates mean(mpg) for each group. mean_mpg is the name of the new summary column.

🧐 Notice: We chain group_by() and summarize() together using the pipe operator %>%. First, group_by(cyl) tells R to work separately by cylinder value. Then, summarize() calculates the mean mpg for each group.

# ✅ 
cyl_means  
# A tibble: 3 × 2
    cyl mean_mpg
  <dbl>    <dbl>
1     4     26.7
2     6     19.7
3     8     15.1

🐱 This is the main curiosity move in Chapter 13. We are no longer asking, “What is the overall mean?” We’re asking, “Does the mean change across groups?” Grouping helps us ask a sharper question without leaving the learning goal.

💡 Test knit. Does cyl_means print as a small table with one row per cylinder value?

🤔 Grouping cars by cyl is useful because cars with different numbers of cylinders often have different fuel efficiency, so one overall average mpg would hide those differences. By grouping first, you can compare the typical mpg for 4-, 6-, and 8-cylinder cars separately.

Explicit vs. Default Naming

If you do not give the summary column a name, dplyr uses the summary expression itself as the column name by default. So summarize(mean(mpg)) creates a column named mean(mpg) instead of a cleaner name like mean_mpg.

🎯 Find the mean mpg for each cylinder count without naming the summary column.

# ⚡ Type this in a Quarto code chunk:
mtcars %>%
  group_by(cyl) %>%
  summarize(mean(mpg))      
# A tibble: 3 × 2
    cyl `mean(mpg)`
  <dbl>       <dbl>
1     4        26.7
2     6        19.7
3     8        15.1

🗣 The default column name is the code itself: mean(mpg). Default names can be confusing when reading or sharing results, so naming summary columns makes tables clearer.

🐱 Notice the problem and build the habit of naming summary columns clearly.

Now that you have seen how group_by() changes one summary calculation, you can ask for several summary statistics at the same time.

Multiple Statistics

🎯 Create several summary columns in one summarize() call, separated by commas.

🐱 This is useful curiosity: one statistic rarely tells the whole story. A mean tells me the center, a standard deviation tells me about spread, and n() tells me how many rows were used for each group.

Use ?n to learn about the n() function.

# ⚡ Type this in a Quarto code chunk:
cyl_stats <- mtcars %>%
  group_by(cyl) %>%
  summarize(mean_mpg = mean(mpg),
            sd_mpg   = sd(mpg),
            n        = n())
# ✅ Verify
cyl_stats
# A tibble: 3 × 4
    cyl mean_mpg sd_mpg     n
  <dbl>    <dbl>  <dbl> <int>
1     4     26.7   4.51    11
2     6     19.7   1.45     7
3     8     15.1   2.56    14

🗣 n() counts how many rows are in each group created by group_by().

🤔 It is similar to count() because both tell you how many observations are in a group, but n() is used inside summarize() when you are also calculating other statistics.

🧐 Notice: length() counts the number of elements in an object. For a vector, that means the number of values. For a data frame, length() counts columns, not rows. That is why n() is the clearer tool here.

💡 Test knit. Does the output show one row for each cylinder value and three summary columns: mean_mpg, sd_mpg, and n?

Multiple Variables

group_by() with one column creates one group for each unique value in that column. group_by() with two columns creates one group for each unique combination of values.

🐱 This is a good moment to make a prediction before running the code. Curiosity is pausing long enough to make a reasonable guess, then checking that guess against the output.

If you see a message about grouped output, keep going. The next section explains what that message means.

ungroup()

When you summarize data that has more than one grouping variable, dplyr may keep part of the grouping structure in the result. That leftover grouping can affect later code, so it is important to check whether your summary table is still grouped.

🐱 We are asking, “What did R keep behind the scenes, and could that affect my next step?”

A. Default behavior: keeps earlier groups

🎯 Show that with two grouping variables, summarize() keeps the earlier group by default.

# ⚡ Type this in a Quarto code chunk:
# A) Default behavior: "drop_last" (keeps earlier groups)
cyl_gear_stats <- mtcars %>%
  group_by(cyl, gear) %>%
  summarize(mean_mpg = mean(mpg))   # no .groups set
`summarise()` has regrouped the output.
ℹ Summaries were computed grouped by cyl and gear.
ℹ Output is grouped by cyl.
ℹ Use `summarise(.groups = "drop_last")` to silence this message.
ℹ Use `summarise(.by = c(cyl, gear))` for per-operation grouping
  (`?dplyr::dplyr_by`) instead.
# ✅  Verify
group_vars(cyl_gear_stats)  # what groups remain?
[1] "cyl"
# ✅ Verify
is_grouped_df(cyl_gear_stats) # expect TRUE
[1] TRUE

🗣 The default behavior is .groups = "drop_last". That means summarize() drops the last grouping variable, gear, but keeps the earlier grouping variable, cyl.

You’ll want to be explicit when you do not want any grouping left.

B. Make it explicit inside summarize()

🎯 Return a plain, ungrouped table by telling summarize() to drop all groups.

# ⚡ Type this in a Quarto code chunk:
# B) Make it explicit: drop *all* groups in the result
cyl_gear_stats_drop <- mtcars %>%
  group_by(cyl, gear) %>%
  summarize(mean_mpg = mean(mpg), .groups = "drop")

🗣 The .groups argument starts with a period and "drop" must be written in quotation marks.

# ✅ Verify
group_vars(cyl_gear_stats_drop)  # expect character(0)
character(0)
# ✅ Verify
is_grouped_df(cyl_gear_stats_drop) # expect FALSE
[1] FALSE

🗣 Using .groups = "drop" tells summarize() to remove all grouping after the summary operation, resulting in a plain data frame without any grouping structure.

💡 Test knit. Does group_vars(cyl_gear_stats_drop) return character(0) and does is_grouped_df(cyl_gear_stats_drop) return FALSE?

C. Alternative: drop groups after summarizing

🎯 Achieve the same ungrouped result by using ungroup() after summarize()

# ⚡ Type this in a Quarto code chunk:
# C) Alternative: drop groups after summarizing
cyl_gear_stats_ungroup <- mtcars %>%
  group_by(cyl, gear) %>%
  summarize(mean_mpg = mean(mpg)) %>%
  ungroup()
`summarise()` has regrouped the output.
ℹ Summaries were computed grouped by cyl and gear.
ℹ Output is grouped by cyl.
ℹ Use `summarise(.groups = "drop_last")` to silence this message.
ℹ Use `summarise(.by = c(cyl, gear))` for per-operation grouping
  (`?dplyr::dplyr_by`) instead.
# ✅  Verify
group_vars(cyl_gear_stats_ungroup)  # expect character(0)
character(0)
# ✅ Verify
is_grouped_df(cyl_gear_stats_ungroup) # expect FALSE
[1] FALSE

🗣 Using ungroup() after summarize() removes all grouping from the resulting data frame. This gives the same ungrouped result as using .groups = "drop" inside summarize().

🐱 When we are done summarizing by groups, we want remove grouping for a plain table.

Pick one method and use it consistently: - Use .groups = "drop" when you want to remove grouping inside summarize(). - Use ungroup() when you want to remove grouping as a separate step after summarizing.

Table 1. Functions for grouped summaries

Function Purpose
count() Counts how many rows fall into each value or combination of values. Useful for frequency tables.
group_by() Creates groups based on one or more variables so later summary functions work separately for each group.
summarize() Creates a smaller summary table by calculating one or more summary statistics.
n() Counts the number of rows in the current group when used inside summarize().
mean() Calculates the average of numeric values.
sd() Calculates the standard deviation, which describes spread around the mean.
max() Finds the largest value in a vector.
unique() Shows the distinct values in a vector. Useful for checking possible groups before summarizing.
length() Counts the number of elements in an object. For a vector, it counts values. For a data frame, it counts columns, not rows.
.groups = "drop" Removes grouping inside summarize() so the result is returned as an ungrouped table.
ungroup() Removes grouping after a grouped operation has already been created.

Chapter Terms

Categorical Data: Data whose values place observations into groups or categories. The categories may have no natural order (nominal) or may have an order with uneven gaps between categories (ordinal). In R, categorical data are often stored as factors.

Center: The middle or typical location of a dataset. Measures of center, such as the mean and median, summarize where values tend to cluster.

Count: The number of observations or values in a dataset, group, or category. In introductory statistics, count tells you how many cases are present.

Frequency: The number of times a value or category appears in a dataset.

Mean: The arithmetic average of a set of numbers, found by adding all values and dividing by the number of values.

Median: The middle value in an ordered dataset. If there is an even number of values, the median is the average of the two middle values.

Numerical Data: Data recorded as numbers, where the values have meaningful magnitudes and consistent intervals. Numerical data are also called quantitative data.

Pipe: An operator that passes the result of one step directly into the next step, letting you write code as a readable sequence of actions instead of nesting functions inside each other. In tidyverse code, the pipe is usually %>%, so x %>% f() means “take x, then apply f()”; in newer base R, a similar built-in pipe is |>.

Range: A simple measure of spread found by subtracting the smallest value from the largest value in a dataset.

Spread: How much the values in a dataset vary or scatter rather than cluster tightly together. Common measures of spread include range, interquartile range (IQR), variance, and standard deviation.

Standard Deviation: A measure of spread that describes how far values typically vary from the mean. A small standard deviation means values are clustered close to the mean, while a large standard deviation means they are more spread out.
